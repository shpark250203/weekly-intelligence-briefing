# SOURCE POLICY

> 이 문서는 CLAUDE.md 7장(Source Rules)의 세부 실행 규칙이다.
> Weekly Brief는 **속보성 정보**를 다루므로, 시장조사 문서보다 **출처와 날짜 기록이 더 중요하다.**

---

## 1. 기본 원칙

- 모든 항목에 **Source명 + 보도일자**를 기록한다. URL은 Sources 섹션에 모은다.
- **보도일자(기사가 나온 날)와 데이터 기준연도(숫자가 가리키는 시점)를 구분한다.**
  예: "2026-09-22 보도 / 2025년 연간 수출액 기준"
- 확인되지 않은 숫자를 사실처럼 쓰지 않는다.
- 평균을 임의로 만들지 않는다. 출처 간 숫자가 다르면 **정의·기간·범위의 차이**를 확인하고 이유를 밝힌다.
- 같은 사안을 여러 매체가 보도한 경우, **원 출처(발표 주체)를 찾아 기록한다.**
  (예: 3개 매체가 보도한 식약처 발표 → Source는 식약처, 확인 경로로 매체 표기)

---

## 2. 정보 유형 구분 (필수)

Weekly Brief의 모든 문장은 아래 4가지 중 하나로 구분된다. 섞어 쓰지 않는다.

| 표기 | 의미 | 예 |
|---|---|---|
| **(사실)** | 공식 발표·통계·공시로 확인된 것 | "관세청 9월 수출 통계: 화장품 수출 XX억 달러" |
| **(회사 발표)** | 기업이 주장한 것. 검증되지 않음 | "회사 발표 — 출시 2주 만에 10만 개 판매" |
| **(언론 해석)** | 매체의 분석·전망 | "언론 해석 — 하반기 경쟁 심화 전망" |
| **[판단]** | Claude의 해석·시사점 | "[판단] 이는 채널 전략 전환 신호로 읽힌다" |

추정이 들어가면 반드시 **`[추정]`** 으로 표시한다.

## 3. Source Tier

### Tier 1 — Primary (최우선)

- 정부기관 / 규제기관: 기획재정부, 한국은행, 통계청, 관세청, 식약처, 공정위, 금융위·금감원
- 해외 기관: FDA, 일본 후생노동성, EU Commission, 중국 NMPA, 각국 통계청
- 기업 공시·IR: DART, 실적발표, 사업보고서, 공식 보도자료
- 산업협회: 대한화장품협회, 대한화장품산업연구원
- 공식 유통 채널 데이터: 올리브영, Sephora, Ulta, @cosme, Amazon 공식

### Tier 2 — Professional Research / 주요 통신·경제지

- 리서치: Circana, NielsenIQ, Euromonitor, Mintel, Kantar, Statista, McKinsey, Bain, BCG
- 통신·경제지: Reuters, Bloomberg, Nikkei, FT, WSJ, 연합뉴스, 한국경제, 매일경제

**유료 리포트 정책**: Press release / Executive summary / 공개 차트 / 신뢰도 높은 2차 인용까지만 사용한다.
접근할 수 없는 유료 보고서 내부 내용을 추정해 쓰지 않는다. 2차 인용 시 **원 출처와 확인 경로를 모두 표기한다.**

### Tier 3 — Industry Media (AXIS 2의 주력 소스)

- 국내 뷰티 전문: **장업신문, CMN, 뷰티누리, 코스모닝, 코스인코리아**
- 해외 뷰티 전문: BeautyMatter, Glossy, CosmeticsDesign, WWD, Cosmetics Business
- 유통·산업 전문: 리테일매거진, 더구루, 전자신문 등

> Tier 3는 AXIS 2에서 **정상적인 주력 출처**다. 단, **정량 수치**(시장 규모, 점유율, 수출액)는
> 가능하면 Tier 1~2로 Cross-check 하고, 못 하면 `Cross-check 미실시`로 표기한다.

### Tier 4 — Secondary / Low Reliability

- 블로그, 커뮤니티, SNS 게시물, 출처 불명 통계, SEO 콘텐츠, AI 생성 요약 기사

**Tier 4는 핵심 수치의 단독 근거로 사용하지 않는다.**
소비자 반응·초기 시그널의 정성적 참고로만 쓰고, 반드시 Tier 4임을 표기한다.

## 3-1. TIER 1 FIRST RULE (필수)

**핵심 정량 데이터는 Tier 2 언론 기사만으로 확정하지 않는다.**

대상: 시장 수치 / 금리 / 환율 / 수출입 / 소비 / 기업실적 / 점유율 / 투자·M&A 금액

절차:

1. **Tier 1 원문을 먼저 찾는다** — 한국은행·통계청·기획재정부·산업통상자원부·관세청·금융위·금감원·한국거래소·식약처·기업 IR·DART
2. Tier 1을 확인했으면 **Tier 2 해설을 함께 붙인다** (`Tier 1 원문 + Tier 2 해설`)
3. Tier 1을 찾지 못했으면 해당 수치 옆에 **반드시** 다음을 표기한다

```
Tier 1 original source not verified
```

이 표기 없이 Tier 2·3 수치를 `FACT`로 제시하는 것을 금지한다.

### 검증 상태 표기

| 표기 | 의미 |
|---|---|
| `Tier 1 verified` | 기관·기업 원문을 직접 확인 |
| `Tier 1 via Tier 2` | 원출처는 Tier 1이나 **매체 경유로만 확인**(원문 미대조) |
| `Tier 1 original source not verified` | Tier 1 원문을 찾지 못함 |

`Tier 1 verification rate` = `Tier 1 verified 수 ÷ 핵심 정량 주장 수` — **매주 QA에 기록한다.**

## 3-2. ARTICLE URL TRACEABILITY (필수)

- 모든 핵심 Issue·신제품에 **개별 기사 URL**을 기록한다.
- 홈페이지·목록 페이지·검색 결과 URL은 **개별 기사 URL의 대체물이 아니다.**
- 확보 실패 시 `Article URL: Not verified`로 표기한다.
- **URL이 없는 기사를 근거로 강한 Trend Signal(Confidence High)을 만들지 않는다.**
- `Article URL 확보율`을 매주 QA에 기록한다.

## 4. Cross-check 절차

다음 항목은 **2개 이상의 독립 출처**로 확인한다.

- 시장 규모 / 성장률 / 점유율
- 수출입 통계
- 기업 매출·영업이익
- 대형 M&A·투자 금액
- 규제 시행일·적용 범위

출처 간 숫자가 다르면 다음 순서로 확인하고 기록한다.

1. 기준 기간이 같은가 (연간 vs 분기, 회계연도 vs 역년)
2. 범위가 같은가 (연결 vs 별도, 국내 vs 글로벌, 카테고리 정의)
3. 통화·환율 기준이 같은가
4. 원 출처가 같은가 (같은 리포트를 다르게 인용했는가)

**평균을 내지 않는다. 두 숫자를 모두 적고 차이의 이유를 쓴다.**

## 5. 제외 기준

다음은 Weekly Brief에 넣지 않는다.

- 보도자료를 그대로 옮긴 홍보성 기사 (새로운 사실이 없는 경우)
- 근거 없는 전망·기대 기사
- 이미 지난 주 Brief에 실린 내용의 반복 (후속 진전이 있으면 `[후속]`으로 표시하고 포함)
- 단발성 사건사고, 단순 인사이동
- 출처가 확인되지 않은 수치

## 6. 커버리지 상태 표기 (5단계)

시간·접근 제약으로 확인하지 못한 영역은 **숨기지 않고 명시한다.**

| 표기 | 의미 |
|---|---|
| `Checked — usable articles found` | 확인했고 사용 가능한 기사를 찾음 |
| `Checked — no significant news` | 확인했으나 선별 기준 충족 기사 없음 |
| `Partial Access` | 일부 구간만 접근 가능 — **확인 범위를 반드시 명시** |
| `Access Blocked` | 접근 차단(로그인·유료·응답 없음 등) |
| `Not Checked` | 확인하지 않음 |

**다섯 가지는 서로 다른 의미다. 구분해서 쓴다.**
특히 `Partial Access`는 확인 범위(날짜 구간)를 적지 않으면 `Not Checked`와 같다.

### Access Blocked 시 Fallback (순서대로 시도)

1. 검색엔진에서 **해당 도메인으로 한정**해 기사 검색
2. 사이트 카테고리·목록 페이지 (페이지네이션 포함)
3. 기사 제목 기반 검색
4. 동일 이슈의 **공식 Source**
5. 다른 전문매체 **Cross-check**

**차단을 우회하지 않으며, 접근하지 못한 내용을 추정하지 않는다.**
1~5를 모두 시도한 뒤에만 `Access Blocked`로 확정한다.
