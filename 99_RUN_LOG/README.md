# 99_RUN_LOG

클라우드 실행의 실패 기록을 남기는 곳이다.

**Gmail 경로 자체가 죽어 실패 메일조차 나가지 못하는 경우의 대체 알림 채널**이다.
Google 인증과 독립된 경로(저장소 커밋)이므로 Gmail 장애와 동시에 죽지 않는다.

## 파일 규칙

- 실패 기록: `<YYYY-Www>_FAILED.md`
- 내용: 실패 단계 / 오류 요약 / 실행 시각(KST·UTC) / 재실행 필요 여부
- **인증정보·수신주소 평문·로컬 경로를 기록하지 않는다.**

정상 실행 시에는 파일을 만들지 않는다. 이 폴더가 비어 있는 것이 정상 상태다.
